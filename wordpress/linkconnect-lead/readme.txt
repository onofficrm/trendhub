파트너 홍보코드(lkCode)로 온오프CPA 상담신청 폼을 삽입합니다.

== Description ==

1. 플러그인 활성화
2. 설정 → 온오프CPA 상담폼 에서 홍보코드 입력
3. 페이지에 숏코드 `[linkconnect_lead]` 또는 블록 「온오프CPA 상담폼」 삽입

== Installation ==

1. zip 업로드 후 활성화
2. 설정에서 lkCode 저장
3. 숏코드/블록 배치
