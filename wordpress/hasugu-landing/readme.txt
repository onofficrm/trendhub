하수구·배관 CPA 상담 랜딩을 워드프레스에 삽입하고 온오프CPA 상담폼과 연동합니다.

== Description ==

1. 플러그인 활성화
2. 설정 → 하수구폴리스 랜딩 에서 홍보코드(lkCode) 입력
3. 페이지 템플릿 「하수구폴리스 랜딩」 선택 또는 숏코드 `[hasugu_landing]` 삽입

== Installation ==

1. zip 업로드 후 활성화
2. 설정에서 lkCode 저장
3. 새 페이지에 템플릿/숏코드 적용
